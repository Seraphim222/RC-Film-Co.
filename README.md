**RC Film Co.**

RC Film Co. is a vintage-inspired web photobooth that allows users to capture memorable moments directly from their browser. Designed with a nostalgic film aesthetic, the application combines the charm of traditional photo booths with a modern, responsive web experience.

**Features**
* Live webcam preview
* Countdown timer before capturing photos
* Vintage-style photo strip layout
* Photo filters and effects
* Download captured photos
* Responsive design for desktop and mobile devices
* Clean and elegant vintage-inspired user interface

**Built With**
* HTML5
* CSS3
* JavaScript
* MediaDevices API (Webcam)
* Canvas API

**About** 

This project was developed to enhance front-end web development skills by exploring browser APIs and creating an interactive user experience. It demonstrates responsive web design, webcam integration, image processing, and modern JavaScript techniques while delivering a classic film-inspired photobooth experience.
